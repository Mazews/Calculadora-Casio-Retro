# 🖩 Casio Retro

Uma calculadora web com visual inspirado nas clássicas calculadoras Casio — projeto feito para praticar HTML, CSS e JavaScript puros.

---

## ✨ Funcionalidades

- Operações matemáticas básicas (soma, subtração, multiplicação, divisão)
- Interface com estética retrô, remetendo ao design físico das calculadoras Casio

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 💻 Rodando localmente

```bash
git clone https://github.com/Mazews/Casio-Retro.git
cd Casio-Retro
```

Depois é só abrir o `index.html` no navegador.
